# Workflows

## Standard Deployment Pipeline

1. Create GitHub repo
2. Build the app
3. Push to GitHub
4. Deploy to Render via API
5. Confirm live URL

## When Given Credentials

1. Save to ~/.config/clawdbot/credentials
2. Set up env vars in .bashrc/.profile
3. Authenticate relevant CLI tools
4. Confirm access works
5. Note in systems.md

## Daily Memory Sync

1. Log significant interactions in logs/YYYY-MM-DD.md
2. Update relevant core/knowledge files
3. Commit and push to ErkMemory
4. Review and consolidate periodically

## Project Request Pattern

1. Create GitHub repo
2. Build requested solution
3. Deploy if applicable
4. Provide all relevant URLs
5. Update projects.md
