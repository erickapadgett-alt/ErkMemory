# Request Patterns

## Common Request Types

### "Create X and deploy"
- Full execution expected
- GitHub + Render pipeline
- Return working URLs

### "Remember X" / "Save X"
- Persist to appropriate memory file
- Confirm it's saved

### "Tell me about X"
- Quick summary
- Get to the point

### "Build X"
- Functional MVP first
- Clean code
- Deploy if web-based

## Inferred Expectations

- Execution > Discussion
- Results > Process explanation
- Working > Perfect
